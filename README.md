# Lista de Tarefas - Atividade 01

Projeto desenvolvido para a disciplina de Frameworks Front-end.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

O projeto foi desenvolvido utilizando Vanilla JavaScript, sem a utilização de frameworks front-end.

## Funcionalidades

- Adicionar tarefas;
- Marcar uma tarefa como concluída;
- Excluir tarefas;
- Adicionar tarefa pressionando Enter;
- Layout responsivo.

## Como executar

Basta abrir o arquivo `index.html` em um navegador.

## Publicação

Após o projeto ser colocado no GitHub, ele pode ser conectado ao Vercel para publicação online.
